# Supported platforms

## Supported

- Windows 11 on x64
- Node.js 22 and npm 10+ for contributors
- Unsigned CI installers for test use until a code-signing certificate and release process are configured

## Not currently supported

macOS and Linux builds are not release targets. They may work for development, but no installer, capture behaviour or end-to-end compatibility is promised until Windows parity and automated platform tests exist.

RDP support in v3 is limited to locally observable client-window evidence. LightTrack does not claim visibility into applications, URLs or records inside the remote session.
